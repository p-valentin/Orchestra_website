Orchestra is a desktop app for building browser automations visually. You compose a flow out of **instruments** — steps like Navigate, Click, Extract and Output — and watch it play in an embedded browser. Under the hood every flow is real [Playwright](https://playwright.dev) code, and you can open it, edit it, and export it as a standalone script at any time.

You don't need to write code to use Orchestra. You don't need to install Node, a browser driver, or anything else — the app ships with everything included. And when a flow outgrows the visual editor, the code is right there.
