Open settings with the **⚙** button in the toolbar. The header shows the app version you're running.

## Browser toolbar

Toggles for the buttons in the embedded browser's toolbar — turn off what you don't use:

- **Orchestrate** — the [recording](/docs/recording) button.
- **Viewport presets** — the desktop / laptop / tablet / mobile size buttons.
- **DevTools** — the `</>` button that opens Chromium DevTools for the page.
- **Pop out browser** — the button that moves the browser to a separate window.

## Toolbar

- **Human-like delay** — the Debug / 🎲 [run-pacing controls](/docs/running).
- **Code editor** — the Code button that opens the [live Playwright editor](/docs/code-export).

## Developer

- **Developer mode** — opens Chromium DevTools for the app itself, to inspect renderer errors, network and IPC traffic.
- **Log file** — crashes, IPC errors and lifecycle events land in a log file; the path is shown here with a copy button. Attach it when [reporting a bug](/docs/troubleshooting#reporting-a-bug).

## Themes

The **🎨** button in the toolbar opens the theme panel. Fourteen built-in themes:

Orchestra · Midnight · Obsidian · Dracula · Nord · Forest · Rose · Gruvbox · Tokyo Night · Monokai · Catppuccin · Synthwave · Solarized · Paper

If none of them is yours, build a **custom theme** — pick your own colors for each part of the UI, save it under a name, and switch between customs and built-ins freely. Theme choice persists across restarts.

## Feedback

The **💬** button opens the feedback form — bugs, ideas, anything. It goes straight to the developer.
